🛍️ Fashion Hub
Fashion Hub is a Frontend web application designed to provide a seamless shopping experience. It features a modern UI, product filtering, and a secure checkout process.

✨ Features
Product Catalog: Browse through various categories of clothing and accessories.

User Authentication: Secure Sign-up and Login functionality.

Shopping Cart: Add/Remove items and update quantities in real-time.

Responsive Design: Optimized for Mobile, Tablet, and Desktop views.
